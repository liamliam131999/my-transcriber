🎙️ My Transcriber

Video သို့မဟုတ် Audio ဖိုင်တွေကို Text အဖြစ်ပြောင်းနိုင်တဲ့ application ဖြစ်ပါတယ်။

🎤 Groq Whisper
Whisper API အသုံးပြုပြီး Audio / Video ကို transcription ပြုလုပ်နိုင်ပါတယ်။
✨ Gemini
Gemini API အသုံးပြုပြီး Audio / Video content ကို text အဖြစ် ပြောင်းနိုင်ပါတယ်။
🗜️ Audio Compressor
Video ထည့်ရင် Video ထဲက Audio ကိုသာ ထုတ်ယူပြီး compressed audio အဖြစ် ပြောင်းပေးပါတယ်။ Audio ထည့်ရင်လည်း Audio ကို ထပ်မံချုံ့ပေးပါတယ်။

🎤 Groq Whisper

Groq Whisper API ဖြင့် Audio / Video transcription ပြုလုပ်ပါ။

✨ Gemini

Gemini API အသုံးပြုပြီး Audio / Video transcription ပြုလုပ်ပါ။

🗜️ Audio Compressor

Video သို့မဟုတ် Audio ဖိုင်ထည့်ပါ။ Output က Audio သာ ထွက်ပါမယ်။

Output: Audio only (.mp4)
Video input: Video track ဖယ်ပြီး Audio သာထုတ်မယ်
Audio input: AAC နဲ့ ပြန် encode လုပ်မယ်
Safety: Output size က input ထက် မလျော့ရင် successful compression အဖြစ် မသတ်မှတ်ပါ။
